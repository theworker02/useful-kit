# North Harbor Studio — Corporate & Diligence Overview

## Purpose

North Harbor Studio is a multi-product portfolio of operator-grade tools for software diligence and delivery. Rather than publishing empty repositories, this studio ships **five working products** with interactive demos, exportable evidence packets, and acquisition-oriented documentation.

## Products

| Product | Domain | Primary buyer |
| --- | --- | --- |
| **Wharf** | Open-source license compatibility | Security / Legal / OSPO |
| **Ledgerline** | Invoice–payment reconciliation | Controllers / AP ops |
| **HarborGate** | OpenAPI contract gates | Platform / API owners |
| **Quillmark** | ADR / RFC diligence packets | Staff+ eng / CTO |
| **Cipherlane** | Config policy & secret-pattern hygiene | AppSec / DevOps |

## Shared diligence standard

Each product includes:

1. Working workspace with sample fixtures
2. Executive summary + scored outcomes
3. Markdown + JSON export artifacts
4. Acquisition brief under `docs/<product>/`
5. Architecture and competitive notes

## Evaluation workflow for buyers

1. Run the studio locally (`npm install && npm run dev`)
2. Open each product route and load samples
3. Export diligence packets from the UI
4. Attach the matching brief from `docs/`

## Commercial narrative

These assets are positioned as **narrow, high-clarity tools** with interpretable outputs suitable for investment memos, security questionnaires, and technical diligence rooms — not novelty toys.
